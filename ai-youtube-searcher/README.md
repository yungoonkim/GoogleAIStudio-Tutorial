# AI YouTube Searcher (AI 유튜브 검색기)

YouTube 시청 화면 스타일의 모던 인터페이스에서 유튜브 영상을 시청하면서, **Google Gemini 3.5 Transcribe**로 타임스탬프 기반 트랜스크립트를 추출하고, **Gemini 3.8 Flash**로 영상 내용에 대해 자유롭게 질문하여 원하는 장면으로 즉시 이동하고 감상할 수 있는 스마트 비디오 탐색 웹 서비스입니다.

---

## 🌟 주요 기능
1. **YouTube 정통 UI/UX**: 실제 유튜브 웹사이트와 유사한 다크 모드 레이아웃
2. **YouTube IFrame Player 연동**:
   * 영상 시청, 재생/일시정지
   * **음향(볼륨) 크기 조절 슬라이더 (0~100%)** 및 음소거
3. **타임스탬프 STT 전사 (`gemini-3.5-transcribe`)**:
   * `yt-dlp`로 오디오를 다운로드한 후 초 단위 타임스탬프와 대사 목록 추출
   * 시간대별 발화 목록 클릭 시 **해당 시간으로 즉시 이동(`seekTo`) 및 자동 재생**
4. **대화형 AI 어시스턴트 (`gemini-3.8-flash`)**:
   * 영상 내용에 대해 질문하면 영상 전체 문맥을 분석하여 답변 제공
   * 답변 내 타임스탬프(`[MM:SS]`) 클릭 시 해당 영상 위치로 즉시 점프
5. **키워드 빠른 탐색**:
   * 찾고 싶은 대사나 단어를 검색하면 일치하는 구간으로 비디오 자동 점프

---

## 🚀 실행 방법

```powershell
# 1. 가상환경 활성화
conda activate myenv

# 2. 서버 실행 (기본 포트: 8080)
python ai-youtube-searcher/app.py
```

브라우저 접속:
👉 **http://127.0.0.1:8080**
